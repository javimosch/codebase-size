# AGENTS.md — codebase-size

A machin CLI that wraps `sloc-guard`, computes a size class + mass score, and
publishes an HTML report to hart.

## Build

```bash
./build.sh
```

This generates `src/template.src` (the embedded `report.html` string),
mints `codebase-size.mfl` with `machin encode`, and compiles to `codebase-size`.

## Source layout

| File                      | Responsibility                                  |
|---------------------------|------------------------------------------------|
| `codebase-size.src`       | MFL source: parsing, counting, scoring, report |
| `report.html`             | HTML template with `{{MARKER}}` placeholders   |
| `build.sh`                | embeds report, encodes .mfl, builds binary     |
| `README.md`               | user docs and GitHub landing page              |
| `src/template.src`        | generated by build.sh; do not edit             |
| `codebase-size.mfl`      | generated canonical MFL; do not edit           |
| `codebase-size`           | generated native binary; gitignored            |

## How to change things

- **Add a CLI flag** — extend `Config`, `parseArgs`, and `main` in
  `codebase-size.src`.
- **List hart reports** — `codebase-size --list --owner <o>` uses `listReports()`.
- **Change the HTML report** — edit `report.html`, then `./build.sh`. Add new
  markers in `report.html` and fill them in `buildReport`.
- **Tune the size scale** — edit `scales()` and `classify()` in
  `codebase-size.src`.
- **Fix counting / exclusions** — change the `sloc-guard stats files` command in
  `scan()`.

## Conventions

- `codebase-size.src` is the hand-edited source. Keep it under 500 LOC; if it
  grows, split into `src/*.src` and adjust `build.sh`.
- Use `machin encode` / `machin build` via `build.sh`; do not commit generated
  artifacts.
- Keep `report.html` plain ASCII so the embedded MFL string is portable.
- The CLI defaults to stdout text, supports `--json`, `--html <file>`, and
  `--hart --owner <o> --artifact <a>`.
