# AGENTS.md — codebase-size

A machin CLI that wraps `sloc-guard`, computes a size class + mass score, and
publishes an HTML report to hart.

## Build

```bash
./build.sh
```

This generates `src/*_template.src` from `report.html` and `compare.html`,
mints `codebase-size.mfl` with `machin encode`, and compiles to `codebase-size`.

## Source layout

| File                      | Responsibility                                  |
|---------------------------|------------------------------------------------|
| `codebase-size.src`       | MFL source: parsing, counting, scoring, main   |
| `src/report.src`          | single-repo report formatting                  |
| `src/compare.src`         | two-repo comparison report formatting          |
| `report.html`             | single-repo HTML template                      |
| `compare.html`            | comparison HTML template                       |
| `build.sh`                | embeds templates, encodes .mfl, builds binary   |
| `README.md`               | user docs and GitHub landing page              |
| `src/*_template.src`      | generated by build.sh; do not edit             |
| `codebase-size.mfl`       | generated canonical MFL; do not edit           |
| `codebase-size`           | generated native binary; gitignored            |

## How to change things

- **Add a CLI flag** — extend `Config`, `parseArgs`, and `main` in
  `codebase-size.src`.
- **List hart reports** — `codebase-size --list --owner <o>` uses `listReports()`.
- **Change the single-repo HTML report** — edit `report.html`, then `./build.sh`.
  Add new markers in `report.html` and fill them in `buildReport` (`src/report.src`).
- **Change the comparison HTML report** — edit `compare.html`, then `./build.sh`.
  Add new markers in `compare.html` and fill them in `buildCompareReport` (`src/compare.src`).
- **Tune the size scale** — edit `scales()` and `classify()` in
  `codebase-size.src`.
- **Fix counting / exclusions** — change the `sloc-guard stats files` command in
  `scan()`.

## Conventions

- `codebase-size.src` is the hand-edited source. Keep it under 500 LOC; if it
  grows, split helpers into `src/*.src` and adjust `build.sh`.
- Use `machin encode` / `machin build` via `build.sh`; do not commit generated
  artifacts.
- Keep `report.html` and `compare.html` plain ASCII so the embedded MFL strings are portable.
- The CLI defaults to stdout text, supports `--json`, `--html <file>`,
  `--hart --owner <o> --artifact <a>`, and `--compare <repo2>` for side-by-side
  comparison reports.
